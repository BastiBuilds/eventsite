# EventWebsite

## 📌 Projektbeschreibung

Die **EventWebsite** ist eine Plattform zur Aggregation und Anzeige von Events in der Schweiz. Ziel des Projekts ist es, eine zentrale Anlaufstelle für lokale Veranstaltungen, Club-Events und andere Events bereitzustellen. Nutzer sollen einfach herausfinden können, welche Events in ihrer Region stattfinden.

## 🎯 Zielsetzung

- **Automatisches Crawlen von Events** aus verschiedenen Quellen (z. B. Eventfrog, Ticketcorner)
- **Regionale Aufteilung** der Events, damit Nutzer gezielt nach Events in ihrer Stadt oder Umgebung suchen können
- **Benutzerfreundliches UI** für eine einfache Event-Suche und Filterung
- **Integration von Club- und lokalen Veranstaltungen**, um ein breites Spektrum an Events abzudecken

## 🛠️ Technologie-Stack

- **Backend**: Python (Django/FastAPI), Node.js
- **Datenbank**: PostgreSQL/MySQL
- **Frontend**: React.js / Next.js
- **Scraping**: BeautifulSoup, Scrapy oder Playwright
- **Hosting**: AWS / Vercel / Netlify
- **CI/CD**: GitHub Actions / GitLab CI
